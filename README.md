# Java 2D Array Program, made by Rochele Fernandez


##  Academic Purpose
This was developed as a programming assignment to demonstrate Java fundamentals and 2D array operation. This is apart of the courswork for the Fundamentals of Programming under Prof. Redentor Bucaling from Quezon City University.

## Description

This is a Java program that demonstrates the use of **two-dimensional (2D) arrays**, multiple classes, loops, and basic array operations.

The program allows users to enter the size and elements of a 2D array. It then calculates the sum of each row and column, displays the results in a matrix format, and checks for duplicate elements.

## Notable Features :DDD

- Accepts user-defined row and column sizes.
- Allows users to input array elements.
- Calculates the sum of each row.
- Calculates the sum of each column.
- Displays the array and its sums in a formatted table.
- Detects duplicate values in the array.
- Uses seven separate Java classes.

## Java Classes

| File | Description |
|---|---|
| `MainProgram.java` | Runs the main program and connects all classes. |
| `ArraySize.java` | Accepts the number of rows and columns. |
| `ArrayElements.java` | Accepts the array elements entered by the user. |
| `RowSum.java` | Calculates the sum of each row. |
| `ColumnSum.java` | Calculates the sum of each column. |
| `ArrayResult.java` | Displays the array, row sums, column sums, and grand total. |
| `DuplicateChecker.java` | Checks the array for duplicate values. |

## 💻 How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the Java files:

   ```bash
   javac MainProgram.java ArraySize.java ArrayElements.java RowSum.java ColumnSum.java ArrayResult.java DuplicateChecker.java
   ```

5. Run the main class:

   ```bash
   java MainProgram
   ```

6. Enter the number of rows, columns, and array elements when prompted.
